    Add items with Siri

    An iPhone or iPad shortcut can add items to your list when you ask Siri. It needs a token, a password that can only add items to your list.

    This shows only once, so copy it now. Treat it like a password: anyone with it can add items to your list.

    Set up the shortcut
    1. In the Shortcuts app, tap + and name the shortcut Add to shopping list. The name is what you'll say to Siri.
    2. Add Ask for Input: type Text, prompt "What do you need?"
    3. Add Get Contents of URL, with the URL Tap the arrow to show more options, then set:
      • Method: POST
      • Headers: add one named Authorization, with the value Bearer, a space, and your token (the Copy button above copies the whole value)
      • Request Body: JSON, with a Text field named name, set to Provided Input
    4. Add Get Dictionary Value: get the value for message in Contents of URL.
    5. Add Show Result with the Dictionary Value. Siri reads it out, like "Added Peanut Butter to the shopping list."

    Then say "Hey Siri, add to shopping list", and tell it what you need.
